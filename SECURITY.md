# Security policy

Security-relevant issues include exposed credentials/tokens, unintended disclosure of screenshots/logs, malicious changes to the single-file runtime, dependency/source substitution and unsafe external-data handling.

Do not post secrets, API keys, account data or sensitive logs/screenshots in a public issue. Use a private channel to contact the repository owner when public disclosure would expose sensitive information.

The runtime depends on remote third-party services/components including Tesseract.js delivery, OCR assets, Google Fonts and UEX API. Dependency or endpoint changes require source/license/security review.

This is a fan utility, not a security product. Static checks are not a substitute for browser/runtime verification.

# GitHub Pages telepítés / deployment

## Magyar

1. Készíts egy új GitHub repositoryt, például `sPg-Refinery-Kep-Elemzo` néven.
2. Töltsd fel a csomag teljes tartalmát a repo gyökerébe.
3. Az `index.html` maradjon a gyökérben.
4. GitHub → **Settings → Pages**.
5. Source: **Deploy from a branch**.
6. Branch: `main`, folder: `/ (root)`.
7. Mentsd el, majd várd meg a publikált URL-t.
8. A `DISCORD_HASZNALAT_HU.md` fájlban cseréld ki a `<GITHUB_PAGES_LINK>` helyőrzőt a valós linkre.

## English

1. Create a new GitHub repository, for example `sPg-Refinery-Kep-Elemzo`.
2. Upload the entire package to the repository root.
3. Keep `index.html` at the root.
4. GitHub → **Settings → Pages**.
5. Source: **Deploy from a branch**.
6. Branch: `main`, folder: `/ (root)`.
7. Save and wait for the published URL.
8. Replace `<GITHUB_PAGES_LINK>` in `DISCORD_HASZNALAT_HU.md` with the actual page URL.

## Recommended repository settings

- Public repository only if you are comfortable publishing the original source code.
- Keep the project non-commercial to remain aligned with the third-party fan/API terms documented in this package.
- Do not upload development screenshots unless you have separately confirmed their redistribution rights.

# Contributing / Közreműködés

Magyar: [DEVELOPMENT/CONTRIBUTING_HU.md](DEVELOPMENT/CONTRIBUTING_HU.md)

English: [DEVELOPMENT/CONTRIBUTING_EN.md](DEVELOPMENT/CONTRIBUTING_EN.md)

Before any code change, read [AGENTS.md](AGENTS.md) and [STATUS.md](STATUS.md).

Do not include private Star Citizen screenshots, raw user logs, secrets, API keys or personal filesystem paths in public commits.

Full release/package work must follow `docs/RELEASE_STANDARD.md`. Ordinary development should not load the full release workflow.

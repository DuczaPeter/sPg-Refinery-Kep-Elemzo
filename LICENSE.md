# Project license status

## Magyar

Az eredeti **sPg Refinery Kép Elemző** alkalmazáskódhoz és saját projekt-dokumentációhoz a repository tulajdonosa még **nem választott explicit projektlicencet**. Az AI nem választ licencet a tulajdonos helyett.

**LICENSE STATUS: UNDECIDED**

A nyilvános repository önmagában nem ad automatikus újrafelhasználási engedélyt; alapértelmezett szerzői jogi szabályok érvényesek addig, amíg a tulajdonos másként nem rendelkezik.

A V4.1 release standard alapján a `LICENSE STATUS RESOLVED` publikus-release gate emiatt **BLOCKED**.

Ez nem érinti a third-party komponensek saját licenceit és Terms feltételeit.

## English

The repository owner has not yet explicitly selected a project license for the original **sPg Refinery Image Analyzer** code and project-authored documentation. The AI does not choose that license.

**LICENSE STATUS: UNDECIDED**

A public repository does not itself grant reuse rights; default copyright rules apply unless and until the owner grants permission or selects a license.

Under Release Standard V4.1, the public-release `LICENSE STATUS RESOLVED` gate is therefore **BLOCKED**.

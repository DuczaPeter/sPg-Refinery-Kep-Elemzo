# Privacy / Adatvédelem

## Magyar

A projektnek nincs saját screenshot-upload backendje. A felhasználó képei a böngészőben kerülnek dekódolásra és OCR-feldolgozásra.

Külső kérések lehetnek a Tesseract.js/OCR runtime assetek, Google Fonts és UEX API 2.0 felé. A UEX felé material/system/market lekérések mennek, nem screenshotok.

A debug log fájlnevet, OCR-szöveget és browser/runtime információt tartalmazhat. Nyilvános issue előtt ellenőrizd.

Ne commitolj privát screenshotot, raw runtime logot, account adatot, API keyt/tokent vagy személyes fájlutat.

## English

The project has no project-owned screenshot-upload backend. User screenshots are decoded and OCR-processed locally in the browser.

External requests can occur for Tesseract.js/OCR runtime assets, Google Fonts and UEX API 2.0. UEX receives material/system/market requests, not screenshots.

Debug logs may contain filenames, OCR text and browser/runtime metadata. Review them before posting publicly.

Do not commit private screenshots, raw logs, account data, API keys/tokens or personal filesystem paths.

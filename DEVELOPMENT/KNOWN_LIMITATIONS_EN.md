# Known limitations — English

- Star Citizen UI changes can invalidate geometry/crop assumptions.
- Different resolution, scaling, HDR, compression or rendering can change OCR behavior.
- UEX is community data, not an official live source of truth.
- UEX endpoints/schema can change.
- The current release requires internet for remote OCR/font/API resources.
- Clipboard/CORS behavior under `file://` is browser-dependent.
- The 109-image R23R6 suite is Freight-only.
- Gemstone regression evidence comes from a separate earlier suite.
- A fresh full R23R6 Refinery Work Order regression is not documented.
- OCR cannot be guaranteed universally error-free; review is an intentional safety path.
